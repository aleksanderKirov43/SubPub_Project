# SubPub_Project
🚀 **Минималистичная шина событий (Event Bus) для Go**

## 📌 Описание
**SubPub** — это асинхронная шина событий, которая позволяет подписчикам получать сообщения **в порядке FIFO (первый пришёл — первый обработан)**, не задерживая друг друга.

Этот пакет реализует механизм **Publisher-Subscriber**, обеспечивая:

- **Гибкость** — множество подписчиков могут подписываться и отписываться от одного `subject`.
- **Высокую производительность** — медленный подписчик не тормозит остальных.
- **Сохранение порядка сообщений** — FIFO-очередь обеспечивает корректную последовательность доставки.
- **Контролируемое завершение (`Close(ctx)`)** — если переданный контекст отменён, шина завершает работу, но активные подписчики продолжают обработку сообщений.
- **Безопасность горутин** — предотвращение утечек и корректное управление потоками.

---

## 🔥 **Возможные сценарии использования**
**SubPub** отлично подходит для:

- **Обмена событиями между микросервисами** — сервис обработки заказов уведомляет логистику о новых заказах.
- **Кэширования в реальном времени** — подписчики могут быстро получать обновления без постоянных запросов к БД.
- **Чат-системы** — сообщение отправляется всем подписчикам без задержек.
- **Аналитики и логирования** — передача метрик событий в обработчики мониторинга.

💡 **Можно интегрировать с Redis или Kafka для более сложных сценариев.**
